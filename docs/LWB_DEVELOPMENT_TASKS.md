# Local Workspace Bridge — 开发任务书

版本：design-v1.0｜日期：2026-09-25

**基线任务书（2026-09-25）：** 当时尚未实施/验收，共 46 项 V1 任务＋8 项扩展任务。当前状态与证据以 [`docs/PROGRESS.md`](PROGRESS.md) 为准；下方原始验收标准保持不变。

任务依赖在同阶段内同样有效。安全与写入任务不得仅依赖 mock 验收；需要 Windows NTFS 实机证据。
